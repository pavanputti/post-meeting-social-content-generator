NETLIFY DROP INSTRUCTIONS
==========================

Files in this folder:
- facebook-privacy.html (Privacy Policy)
- facebook-terms.html (Terms of Service)
- facebook-data-deletion.html (Data Deletion Instructions)

HOW TO DEPLOY TO NETLIFY:
==========================

1. Go to: https://app.netlify.com/drop
   (No account needed - just drag and drop!)

2. Drag this entire "netlify" folder onto the Netlify Drop page

3. Wait a few seconds for Netlify to deploy

4. You'll get a URL like: https://random-name-123.netlify.app

5. Your Facebook App URLs will be:
   - Privacy Policy: https://your-netlify-url.netlify.app/facebook-privacy.html
   - Terms of Service: https://your-netlify-url.netlify.app/facebook-terms.html
   - Data Deletion: https://your-netlify-url.netlify.app/facebook-data-deletion.html

6. Copy these URLs and use them in Facebook Developer Portal:
   - Go to: https://developers.facebook.com/apps/
   - Select your app (ID: 25544648371838914)
   - Go to Settings → Basic
   - Add the URLs in the respective fields

That's it! The pages will be live and accessible for Facebook to validate.
